# 坦克大战 · Tank Battle

一个经典 Battle City（坦克大战）风格的小游戏，**单文件 HTML**，无需安装、无需联网、无任何依赖 —— 双击 `index.html` 就能玩。

纯 HTML5 Canvas + 原生 JavaScript 实现，全部代码（约 1000 行）都在一个文件里。

## 在线试玩

部署到 GitHub Pages 后可直接访问：`https://<你的用户名>.github.io/tank-battle/`

## 玩法

驾驶坦克守住屏幕下方的**鹰徽基地**，消灭每一关的全部敌军坦克。

- **基地被摧毁** → 立即失败（与剩余生命无关）
- **生命耗尽** → 失败
- 打完全部 5 关 → 胜利

> 注意：基地只会被**敌方**炮火摧毁。自己误射只会被挡下，不会自毁。

## 操作

| 按键 | 功能 |
| --- | --- |
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 移动 |
| `空格` 或 `J` | 开炮 |
| `P` | 暂停 / 继续 |
| `M` | 静音开关 |
| `Enter` | 开始 / 重新开始 |

手机上会自动显示虚拟方向键与开火按钮。

## 游戏元素

**地形**

| 地形 | 坦克 | 炮弹 |
| --- | --- | --- |
| 砖墙 | 阻挡 | 可击碎 |
| 钢墙 | 阻挡 | 需 3 级火力才能击碎 |
| 河流 | 阻挡 | 穿过 |
| 树林 | 穿过 | 穿过（会遮挡视线） |

**敌军类型**

| 类型 | 速度 | 生命 | 分值 |
| --- | --- | --- | --- |
| 普通 | 慢 | 1 | 100 |
| 快速 | 快 | 1 | 200 |
| 炮击 | 慢 | 1（炮弹快） | 300 |
| 装甲 | 慢 | 4 | 400 |

装甲坦克每中一弹会变色，击毁**闪红**的敌军会掉落道具。

**道具**

| 道具 | 效果 |
| --- | --- |
| ★ 星 | 火力升级（三级：炮弹更快 → 双发 → 可破钢墙） |
| 手雷 | 立即消灭场上所有敌军 |
| 头盔 | 获得一段无敌护盾 |
| 时钟 | 冻结敌军一段时间 |
| 铁锹 | 基地外墙暂时变成钢墙 |
| 1UP | 生命 +1 |

## 本地运行

```bash
git clone https://github.com/<你的用户名>/tank-battle.git
cd tank-battle
# 直接用浏览器打开即可
start index.html        # Windows
open index.html         # macOS
```

也可以起个静态服务器（可选）：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术说明

- 逻辑帧固定为 60 FPS（累加器 + `requestAnimationFrame`），与显示器刷新率无关
- 地图为 26×26 的 16px 瓦片网格，画布 416×416，用 CSS 缩放并保持像素风（`image-rendering: pixelated`）
- 关卡用 13×13 的字符画定义，每个字符展开成 2×2 瓦片（`B` 砖 / `S` 钢 / `W` 水 / `F` 林）
- 音效由 Web Audio API 实时合成，没有任何音频文件
- 最高分存在 `localStorage`

想自己改关卡？编辑 `index.html` 里的 `LEVELS` 数组即可。**注意中间一列（第 6 个字符，对应基地所在的两列瓦片）必须放砖或钢**，否则顶部中央出生点的敌人会有一条直通基地的射击通道，游戏将毫无还手余地。
